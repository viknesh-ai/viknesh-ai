### About

Software engineer at **Société Générale**, working on the bank's enterprise data platform — metadata, cataloguing and governance tooling used across business lines. Day to day that means Java/Spring Boot services, a React + TypeScript front end, and the kind of constraints that come with regulated financial data: lineage, auditability, and correctness over cleverness.

Outside of that I'm working through a self-directed track on **production AI engineering** — retrieval systems, agents, evaluation, and deployment. Less model research, more of what it takes to run an LLM system that doesn't fall over.

- B.Tech in **Artificial Intelligence & Data Science**
- Interested in data quality, retrieval infrastructure, and agentic systems
- Open to conversations about AI engineering roles and open-source collaboration

### Selected work

**[genai-labs](https://github.com/viknesh-ai/genai-labs)** — `Python` `FastAPI`

A single codebase built as a progressive course in itself: one FastAPI application that works through API versioning, LLM integrations, retrieval-augmented generation, multimodal input, and deployment. Structured as phases rather than disconnected demos, so each layer builds on the last.

**[Fake image detection using CNN](https://github.com/viknesh-ai/Fake_image-_detection-using-CNN)** — `Jupyter Notebook` `Deep Learning`

Convolutional network trained to distinguish manipulated images from authentic ones — data preparation, model architecture, and evaluation end to end.

**[gen-ai---llm-](https://github.com/viknesh-ai/gen-ai---llm-)** — `Jupyter Notebook`

Working notebooks on generative models and LLM behaviour — prompting, fine-tuning experiments, and evaluation.
